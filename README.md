# FPPFootball

First-person multiplayer football for mobile.

## Setup (everyone)
1. Install Unity Hub and **Unity 6000.3.28f1** with Android Build Support (OpenJDK, SDK & NDK).
2. Install Git for Windows (includes Git LFS) and GitHub Desktop.
3. Run `git lfs install` once.
4. Clone this repo, then in Unity Hub: Add > Add project from disk.
5. Don't change the Unity version without agreeing as a team.

## Daily workflow
- `git pull` before you start.
- Work on your own branch, commit small, push often.
- Merge to main through pull requests.
- Don't edit the same scene as a teammate at the same time.
